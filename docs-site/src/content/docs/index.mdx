This guide explains how to evaluate large language models, grounded in verified primary sources. Every claim is traceable to the primary-source citations on each page. It is documentation only, no code.

## How to Use This Guide

1. Start with the ten evaluation types in [Types of evaluations](/02-types-of-evals/).
2. Define the vocabulary in the [Glossary](/08-glossary/).
3. Read the page for the eval you need (09 through 18).
4. Pick datasets from the [Benchmarks directory](/04-benchmarks-directory/).
5. Pick software from [Tools and frameworks](/05-tools/).
6. Follow [How to build evaluations](/06-how-to-build-evals/) to assemble one.
7. Ground your decisions in the [Case studies](/07-case-studies/).

## House Rules

- Every benchmark and tool is verified against a primary source, with access dates recorded.
- Contamination, English-centric bias, eval-awareness, and judge bias are flagged wherever relevant.
